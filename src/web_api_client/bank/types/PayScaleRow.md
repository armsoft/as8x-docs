Հաճախորդի Գանձման տեսակներ (TUNINGS) աղյուսակ։ Նախատեսված է հաճախորդի ստեղծման/խմբագրման և տվյալների ստացման համար։

```c#
public class PayScaleRow
{
    /// <summary> Կոդ </summary>
    public string PayCode { get; set; }

    /// <summary> Գանձ.տես. </summary>
    public string Tuning { get; set; }
}
```
