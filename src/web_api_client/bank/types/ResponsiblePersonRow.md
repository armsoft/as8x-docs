Հաճախորդի Պատասխանատուների ցուցակ (RESP) աղյուսակի տողի տվյալները։ Նախատեսված է հաճախորդի ստեղծման/խմբագրման և տվյալների ստացման համար։

```c#
public class ResponsiblePersonRow
{
    /// <summary> Պատասխանատուների ցուցակ </summary>
    public string RespName { get; set; }

    /// <summary> Անձը հաստատող փաստաթուղթ </summary>
    public string RespPasCode { get; set; }
}
```
